## 👋 Welcome

TabaLabs is a small lab where I build tools I wish already existed: focused libraries that do one job well, are easy to set up, and are safe to use in production.

Every project here follows the same rules:

- **Five-minute setup.** Install, add a few lines, and it works.
- **Small and focused.** One clear purpose per library, no bloat.
- **Tested and documented.** Tests run on every change, and every package has a clear README and examples.
- **Open source.** Free to use and modify under the MIT license.
